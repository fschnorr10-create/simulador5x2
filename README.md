# Simulador 5 × 2 — Schnorr

Aplicação estática de planejamento de jornadas, cobertura da equipe e custos, com orientação de contratação rural.

Endereço: https://simulador5x2.advschnorr.com.br/

## Publicação

GitHub Pages, branch main, diretório raiz. O arquivo index.html contém o aplicativo completo e a logo oficial. Sem APIs, cadastro ou envio das entradas a servidor. CNAME identifica o subdomínio; .nojekyll mantém a publicação estática.
